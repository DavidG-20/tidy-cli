# Reglas del proyecto `tidy-cli`

- Este proyecto usa **Python 3.10+** gestionado con **`uv`** (`pyproject.toml` + `uv.lock`).
- Código fuente en `src/tidy_cli/` y pruebas en `tests/`.
- Usa nombres descriptivos en inglés para código (variables, funciones, clases) y mensajes claros para el usuario en consola.
- Antes de agregar o modificar funcionalidad importante, explica brevemente qué archivos se van a tocar y por qué.
- Consulta las skills en `.agents/skills/` al diseñar módulos (`arquitectura-cli`) o manipular archivos en disco (`operaciones-seguras`).
